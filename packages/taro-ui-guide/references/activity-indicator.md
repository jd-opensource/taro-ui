# ActivityIndicator 加载

> 按需阅读：仅在使用本组件时打开此文件。

## 导出

`AtActivityIndicator`

## 引入

```tsx
import { AtActivityIndicator } from 'taro-ui'
```

## 样式（按需）

```scss
@import 'taro-ui/dist/style/components/activity-indicator.scss';
```

## 源码与类型

- 实现：`packages/taro-ui/src/components/activity-indicator/`
- 类型：`packages/taro-ui/types/activity-indicator.d.ts`
- 官方文档：`docs/docs/components/activity-indicator.md`

## 主要 Props

### `AtActivityIndicatorProps`

| Prop | 可选 | 说明 |
|------|------|------|
| `size` | 是 | loading 图的大小 |
| `mode` | 是 | 元素的类型 |
| `color` | 是 | loading 图的颜色 |
| `content` | 是 | 元素的内容文本 |
| `isOpened` | 是 | 控制元素显示隐藏 |
