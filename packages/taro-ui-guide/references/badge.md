```tsx
import { AtBadge } from 'taro-ui'
```

## 样式（按需）

```scss
@import 'taro-ui/dist/style/components/badge.scss';
```

## 源码与类型

| `value` | 是 | 角标内容 |
| `maxValue` | 是 | 角标最大值 |
