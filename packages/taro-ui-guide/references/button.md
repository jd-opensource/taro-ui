# Button 按钮

> 按需阅读：仅在使用本组件时打开此文件。

## 导出

`AtButton`

## 引入

```tsx
import { AtButton } from 'taro-ui'
```

## 样式（按需）

```scss
@import 'taro-ui/dist/style/components/button.scss';
```

## 源码与类型

- 实现：`packages/taro-ui/src/components/button/`
- 类型：`packages/taro-ui/types/button.d.ts`
- 官方文档：`docs/docs/components/button.md`

## 主要 Props

### `AtButtonProps`

| Prop | 可选 | 说明 |
|------|------|------|
| `size` | 是 | 按钮的大小 |
| `type` | 是 | 按钮的类型 |
| `circle` | 是 | 设置按钮圆角 |
| `full` | 是 | 是否通栏样式（即按钮宽度为屏幕宽度时的样式） |
| `loading` | 是 | 设置按钮的载入状态 |
| `disabled` | 是 | 设置按钮为禁用态（不可点击） |
| `onClick` | 是 | 点击按钮时触发 |
