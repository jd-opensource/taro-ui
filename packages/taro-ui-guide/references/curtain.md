# Curtain 幕帘

> 按需阅读：仅在使用本组件时打开此文件。

## 导出

`AtCurtain`

## 引入

```tsx
import { AtCurtain } from 'taro-ui'
```

## 样式（按需）

```scss
@import 'taro-ui/dist/style/components/curtain.scss';
```

## 源码与类型

- 实现：`packages/taro-ui/src/components/curtain/`
- 类型：`packages/taro-ui/types/curtain.d.ts`
- 官方文档：`docs/docs/components/curtain.md`

## 主要 Props

### `AtCurtainProps`

| Prop | 可选 | 说明 |
|------|------|------|
| `isOpened` | 是 | 是否开启 |
| `closeBtnPosition` | 是 | 关闭图标位置 'top', 'top-left', 'top-right', 'bottom', 'bottom-left', 'bottom-right' |
| `onClose` | 否 | 点击关闭按钮触发事件 |
