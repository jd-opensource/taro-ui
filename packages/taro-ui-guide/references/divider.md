# Divider 分割线

> 按需阅读：仅在使用本组件时打开此文件。

## 导出

`AtDivider`

## 引入

```tsx
import { AtDivider } from 'taro-ui'
```

## 样式（按需）

```scss
@import 'taro-ui/dist/style/components/divider.scss';
```

## 源码与类型

- 实现：`packages/taro-ui/src/components/divider/`
- 类型：`packages/taro-ui/types/divider.d.ts`
- 官方文档：`docs/docs/components/divider.md`

## 主要 Props

### `AtDividerProps`

| Prop | 可选 | 说明 |
|------|------|------|
| `content` | 是 | 分隔符文字 |
| `height` | 是 | 分隔符高度，会自动转 rem,rpx |
| `fontColor` | 是 | 文字颜色 |
| `fontSize` | 是 | 文字大小，会自动转 rem,rpx |
| `lineColor` | 是 | 分割线颜色 |
