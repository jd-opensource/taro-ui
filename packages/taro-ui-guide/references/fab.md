# Fab 悬浮按钮

> 按需阅读：仅在使用本组件时打开此文件。

## 导出

`AtFab`

## 引入

```tsx
import { AtFab } from 'taro-ui'
```

## 样式（按需）

```scss
@import 'taro-ui/dist/style/components/fab.scss';
```

## 源码与类型

- 实现：`packages/taro-ui/src/components/fab/`
- 类型：`packages/taro-ui/types/fab.d.ts`
- 官方文档：`docs/docs/components/fab.md`

## 主要 Props

### `AtFabProps`

| Prop | 可选 | 说明 |
|------|------|------|
| `size` | 是 | 大小尺寸 |
| `onClick` | 是 | 点击标签时触发 |
