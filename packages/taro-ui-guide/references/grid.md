# Grid 宫格

> 按需阅读：仅在使用本组件时打开此文件。

## 导出

`AtGrid`

## 引入

```tsx
import { AtGrid } from 'taro-ui'
```

## 样式（按需）

```scss
@import 'taro-ui/dist/style/components/grid.scss';
```

## 源码与类型

- 实现：`packages/taro-ui/src/components/grid/`
- 类型：`packages/taro-ui/types/grid.d.ts`
- 官方文档：`docs/docs/components/grid.md`

## 主要 Props

### `AtGridProps`

| Prop | 可选 | 说明 |
|------|------|------|
| `data` | 否 | 宫格布局数据源 |
| `columnNum` | 是 | 每一列有多少个 |
| `hasBorder` | 是 | 是否有边框 |
| `mode` | 是 | 布局模式 |
| `onClick` | 是 | 点击宫格触发的事件 |
