# Icon 图标

> 按需阅读：仅在使用本组件时打开此文件。

## 导出

`AtIcon`

## 引入

```tsx
import { AtIcon } from 'taro-ui'
```

## 样式（按需）

```scss
@import 'taro-ui/dist/style/components/icon.scss';
```

## 源码与类型

- 实现：`packages/taro-ui/src/components/icon/`
- 类型：`packages/taro-ui/types/icon.d.ts`
- 官方文档：`docs/docs/components/icon.md`
