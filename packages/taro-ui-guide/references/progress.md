# Progress 进度条

> 按需阅读：仅在使用本组件时打开此文件。

## 导出

`AtProgress`

## 引入

```tsx
import { AtProgress } from 'taro-ui'
```

## 样式（按需）

```scss
@import 'taro-ui/dist/style/components/progress.scss';
```

## 源码与类型

- 实现：`packages/taro-ui/src/components/progress/`
- 类型：`packages/taro-ui/types/progress.d.ts`
- 官方文档：`docs/docs/components/progress.md`

## 主要 Props

### `AtProgressProps`

| Prop | 可选 | 说明 |
|------|------|------|
| `color` | 是 | 元素的颜色 |
| `status` | 是 | 元素的状态 |
| `percent` | 是 | 元素的进度 |
| `strokeWidth` | 是 | 元素的规格 |
| `isHidePercent` | 是 | 是否隐藏文字 |
