# Tag 标签

> 按需阅读：仅在使用本组件时打开此文件。

## 导出

`AtTag`

## 引入

```tsx
import { AtTag } from 'taro-ui'
```

## 样式（按需）

```scss
@import 'taro-ui/dist/style/components/tag.scss';
```

## 源码与类型

- 实现：`packages/taro-ui/src/components/tag/`
- 类型：`packages/taro-ui/types/tag.d.ts`
- 官方文档：`docs/docs/components/tag.md`

## 主要 Props

### `AtTagProps`

| Prop | 可选 | 说明 |
|------|------|------|
| `size` | 是 | 大小尺寸 |
| `type` | 是 | 样式类型 |
| `name` | 是 | 标签名字 |
| `circle` | 是 | 是否大圆角 |
| `active` | 是 | 是否为选中态 |
| `disabled` | 是 | 是否为禁用态 |
| `onClick` | 是 | 点击标签时触发，返回标签名字和状态的对象 |
