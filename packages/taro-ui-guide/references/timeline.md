# Timeline 时间轴

> 按需阅读：仅在使用本组件时打开此文件。

## 导出

`AtTimeline`

## 引入

```tsx
import { AtTimeline } from 'taro-ui'
```

## 样式（按需）

```scss
@import 'taro-ui/dist/style/components/timeline.scss';
```

## 源码与类型

- 实现：`packages/taro-ui/src/components/timeline/`
- 类型：`packages/taro-ui/types/timeline.d.ts`
- 官方文档：`docs/docs/components/timeline.md`

## 主要 Props

### `AtTimelineProps`

| Prop | 可选 | 说明 |
|------|------|------|
| `pending` | 是 | 最后一项是否为未完成态 |
| `items` | 否 | 需展示的内容 |
| `onClickItem` | 是 | 点击 item 触发的事件 |
